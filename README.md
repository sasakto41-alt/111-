# Majestic Text Helper v3.4.0

Хранилище игровых фраз для Majestic RP и быстрая вставка в чат.
**Enter никогда не нажимается программой** — подтверждение чата всегда за вами.

## Что нового в v3.4.0 — «починили F6»

1. **Меню-клавиша (F6) теперь ловится опросом клавиатуры (GetAsyncKeyState)**,
   а не системным хуком. Раньше F6 пропадала, когда: игра (особенно с античитом)
   мешала хуку; Windows отключала «медленный» хук по таймауту; игра была запущена
   от администратора, а программа — нет. Опрос читает состояние клавиш напрямую —
   от всего этого не зависит. Открывает И закрывает меню.
2. **Кнопка «💾 Сохранить настройки»** — принудительно применяет и сохраняет ВСЕ
   поля страницы настроек (хоткеи, вставка, окно игры, пояс, трей, белый список),
   показывает ✓ или предупреждение. Хоткеи после сохранения перезапускаются.
3. **Кнопка «Проверить меню-клавишу (10 с)»** — нажмите F6 после запуска теста:
   программа честно покажет, доходит ли нажатие (✓ зелёным или ✗ с причинами).
4. В настройках виден **статус перехвата клавиш**; каждое срабатывание F6 и все
   шаги запуска пишутся в `error.log`.

## Что нового в v3.3.0 — «починили запуск»

1. **Окно теперь видно в панели задач** (раньше использовался флаг Qt.Tool —
   окна не было в панели, и его легко было «потерять» за полноэкранной игрой).
2. **Сборка стала папочной (onedir)** — `dist\MajesticTextHelper\`.
   Антивирусы намного реже помечают такие сборки как угрозу; исчезают
   молчаливые проблемы распаковки onefile; запуск быстрее.
3. **Диагностическая сборка с консолью** — `dist\MajesticTextHelper_debug\`.
   Если основная не открывается, запустите её: чёрное окно покажет точную
   ошибку (или `python main.py --diag` из исходников).
4. **Журнал запуска до всех импортов** — `error.log` рядом с exe (иначе
   `data\error.log`, иначе `%APPDATA%\MajesticTextHelper\error.log`).
   Пишутся все шаги: импорт Qt → блокировка второго экземпляра → окно →
   трей → хоткеи. faulthandler сохраняет даже нативные падения Qt.
5. **Защита от повторного запуска** — если программа уже висит в трее,
   второй запуск не «молчит», а показывает подсказку, где искать окно.
6. **Окно с ошибкой на любом сбое** — показывается через WinAPI, работает
   даже если сам Qt не смог загрузиться.

## Что нового в v3.2.1

- **Часовой пояс госволны**: Настройки → «Часовой пояс госволны» —
  «Как на компьютере» или UTC−12…UTC+14 (включая UTC+3:30 и т.п.).
  Влияет на «Подобрать время» и проверку правил; на странице «Госволна»
  видно, какой пояс используется и сколько на нём времени.
- **run.bat** — запуск из исходников без сборки.

## Что нового в v3.2.0

1. **Способ вставки «Копировать в буфер»** — самый надёжный. Программа просто
   копирует текст в буфер обмена и переключает вас в окно игры. Вы сами
   нажимаете `T` и вставляете `Ctrl+V`. Игра уже не может «съесть» ввод.
2. **Раздел «Госволна»** — помощник подачи государственных волн по памятке:
   подбор слотов (10–120 мин, сетка 10 мин, ≥20 мин между своими, ≤3 в час),
   автосборка команд `/dep` → «Занял гос.волну» → `/report` → освобождение,
   шаблоны `/gnews` для Палето-Бэй и Сенди-Шорс, сохранение в библиотеку,
   ссылка на Discord-канал.
3. **Окно игры (цель переключения)** — в настройках укажите часть заголовка
   окна игры (например `Majestic`) — программа сама найдёт окно и переключится.
4. **Права администратора** — exe сам запрашивает запуск от администратора
   (`uac_admin`), чтобы хоткеи работали, даже если игра запущена от админа.

## Быстрый старт

### Вариант 1: собрать exe
1. Установите Python 3.10+ (галочка *Add Python to PATH*).
2. Запустите `build_exe.bat` — соберутся ОБЕ версии.
3. Запускайте: `dist\MajesticTextHelper\MajesticTextHelper.exe`
   Папку можно переносить целиком (exe + `_internal` вместе).
4. Диагностическая версия с консолью:
   `dist\MajesticTextHelper_debug\MajesticTextHelper_debug.exe`

### Вариант 2: запуск без сборки
```
pip install -r requirements.txt
python main.py
```
или просто запустите `run.bat` — он сам установит зависимости и запустит.

Полезные ключи: `python main.py --diag` (диагностика), `--version`,
`--smoke` (самопроверка), `--hidden` (запуск в трей).

## Первый запуск — рекомендации

1. **Запускайте от администратора** (exe сам попросит — жмите «Да»).
2. Откройте **Настройки → Окно игры → «Захватить активное окно (10 с)»**,
   кликнув по окну игры за 10 секунд — поля заполнятся сами. Нажмите
   «Проверить» — должно найтись минимум 1 окно.
3. Нажмите **«💾 Сохранить настройки»** (вверху страницы настроек).
4. Проверьте F6 кнопкой **«Проверить меню-клавишу (10 с)»**.
5. Если вставка в игре не срабатывает — выберите
   **Способ вставки: «Копировать в буфер»**. Тогда в игре: `T` → `Ctrl+V` → `Enter`.
6. Хоткей меню по умолчанию — `F6`. Меню поверх игры: выберите фразы,
   клик по карточке — вставка/копирование, `Esc` — скрыть.

## Способы вставки (Настройки)

| Способ | Как работает |
|---|---|
| Печатать посимвольно (Unicode) | Сама открывает чат (`T`), ждёт, печатает текст |
| Вставить через Ctrl+V | Сама открывает чат (`T`), копирует, жмёт `Ctrl+V` |
| **Копировать в буфер** | Только копирует и переключает в игру — `T` и `Ctrl+V` нажимаете сами |

## Горячие клавиши

- `F6` (настраивается) — показать/скрыть меню поверх игры.
- Для каждой фразы можно назначить свою клавишу (`F1–F24`, `ctrl+1` и т.п.).
- Фразы из категории «Госволна» удобно вешать на `F7`…`F9`.

## Госволна — памятка (встроена в программу)

- Занимать волну: **за 10–120 минут** до вещания.
- Слоты: **XX:00 / XX:10 / XX:20 / XX:30 / XX:40 / XX:50**.
- Между объявлениями вашей организации: **≥ 20 минут**; общих: **≥ 10 минут**.
- Не более **3 волн в час**. Повторное занятие — после публикации объявления.
- Порядок: проверить занятость → занять (если тишина 5 минут) →
  «Занял гос.волну» → объявление в Discord → `/report` → освободить.
- Часовой пояс сервера меняется в Настройках — подбор слотов подстроится.

## Данные

- Всё хранится в `data\data.json` рядом с программой (portable).
- Если файл повреждён — программа делает бэкап `*.corrupt-*.json` и стартует заново.
- Тест без ввода: `set MTH_DRYRUN=1` перед запуском — нажатия только логируются.

## Сборка

`build_exe.bat` ставит зависимости и собирает через PyInstaller:
- `majestic_helper.spec` → `dist\MajesticTextHelper\` (основная, без консоли);
- `majestic_helper_debug.spec` → `dist\MajesticTextHelper_debug\` (с консолью).
Обе папочные (onedir), с иконкой и `uac_admin=True`.

## Если exe вообще не открывается — по порядку

1. **Посмотрите в панель задач (полоса внизу экрана)** — v3.3.0 показывает
   окно там. Если видна иконка «M» — просто кликните по ней.
2. **Программа уже запущена в трее?** Ищите иконку «M» возле часов
   (возможно, нужно нажать «^» — показать скрытые значки). Двойной клик —
   открыть окно. С v3.3.0 повторный запуск сам подскажет об этом.
3. **SmartScreen**: если появилось синее окно «Windows защитила ваш ПК» —
   нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. **Запрос администратора (UAC)**: жмите **«Да»**. Если отменить —
   программа не откроется.
5. **Антивирус/Defender**: откройте «Безопасность Windows → Защита от
   вирусов → Журнал защиты». Если MajesticTextHelper там есть — верните из
   карантина и добавьте папку `dist\MajesticTextHelper` в исключения
   (программа перехватывает клавиатуру для хоткеев, поэтому антивирусы
   иногда ошибочно ругаются; код открыт — можно проверить сами).
6. **Запустите диагностическую версию**
   `dist\MajesticTextHelper_debug\MajesticTextHelper_debug.exe` —
   в чёрном окне консоли будет видна причина.
7. **Проверьте журнал**: `error.log` рядом с exe или `data\error.log` —
   там по шагам видно, где запуск остановился. Пришлите файл разработчику.
8. **Обходной путь без exe**: установите Python и запустите `run.bat` —
   если программа откроется так, значит проблема в антивирусе/SmartScreen.

## FAQ

**F6 в игре не открывает меню.** С v3.4.0 F6 ловится опросом клавиатуры и
работает даже при игре от администратора. Если всё равно не работает:
1. Нажмите **«💾 Сохранить настройки»** — хоткеи перезапустятся.
2. В настройках нажмите **«Проверить меню-клавишу (10 с)»** и нажмите F6:
   - ✓ зелёное — перехват работает, проблема была в старой версии;
   - ✗ — клавишу заняла другая программа: смените меню-клавишу (например
     на `F7`), сохраните и проверьте снова.
3. Игра в полноэкранном ЭКСКЛЮЗИВНОМ режиме «съедает» любые хоткеи —
   переключите игру в **«Окно без рамки»** (безрамочный режим).
4. Если игра запущена от администратора, а программа запущена из исходников
   без прав — запустите exe (он сам просит права) или run.bat от админа.

**Текст печатается не туда.** Укажите «Окно игры» в настройках — программа
сама переключится на нужное окно перед вставкой.

**Безопасный режим:** способ «Копировать в буфер» — программа не нажимает
вообще никаких клавиш, только кладёт текст в буфер обмена.
